# AidConnect - Humanitarian Solidarity & Volunteer Network

[![PHP](https://img.shields.io/badge/PHP-8.2-blue.svg)](https://www.php.net/)
[![MySQL](https://img.shields.io/badge/MySQL-8.0-orange.svg)](https://www.mysql.com/)
[![Bootstrap](https://img.shields.io/badge/Bootstrap-5-purple.svg)](https://getbootstrap.com/)

AidConnect is an online mutual-aid platform connecting volunteers, donors, and humanitarian associations with citizens in need.

## Core Modules
- **Authentication & Roles:** Secure registration, bcrypt password hashing, and session authentication.
- **Volunteer Opportunities:** Publishing, filtering, and applying for localized community missions.
- **Mutual-Aid Feed:** Real-time publication of requests and aid announcements.
- **Admin BackOffice:** Member directory, role management, and content moderation.
